# Excel Corporate Training

Practical, business-realistic Excel exercises built to develop real-world
spreadsheet skills for finance, supply chain, and logistics workflows.

## About this repository

I'm an Economics student about to start an internship at **NUCLEP**, a
Brazilian state-owned company in the energy and defense sector. While I hold
a Basic-to-Advanced Excel certification, I wanted hands-on experience with
the kind of formulas, structures, and reporting logic actually used in
corporate day-to-day work — not just certification-level theory.

This repository documents that progression: each exercise simulates a
realistic business task (a manager or supervisor assigning a deliverable),
and each solution is built, tested, and explained with the business logic
behind the formula — not just the syntax.

## Structure

Exercises are organized by learning module. Each module groups a family of
related Excel skills, and each exercise inside it targets one specific
function or concept, increasing gradually in complexity.

```
excel-corporate-training/
├── modulo-01-logica-condicional/
│   ├── M1.1-controle-abastecimento-frota/
│   ├── M1.2-...
├── modulo-02-...
```

## Roadmap

| Module | Focus |
|---|---|
| 01 | Conditional logic & lookup (SUMIFS, COUNTIFS, XLOOKUP, IFERROR, IFS) |
| 02 | Text handling & data cleaning |
| 03 | Date functions |
| 04 | Advanced lookup (INDEX/MATCH, multi-criteria XLOOKUP) |
| 05 | Dynamic array functions (FILTER, UNIQUE, SORT) |
| 06 | Data validation & conditional formatting |
| 07 | PivotTables |
| 08 | Dashboards |
| 09 | Naming conventions, structure, and workbook best practices |
| 10 | Power Query & VBA/Macros — conceptual bridge to desktop Excel |

## Tools

All exercises are built and solved in **Excel for the Web**, since that's my
current working environment. Function names and syntax follow the English
locale (e.g. `XLOOKUP`, `SUMIFS`) for direct compatibility with international
documentation and future desktop use.
